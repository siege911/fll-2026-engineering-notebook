# FLL Robotics 2026 — Program Foundation (BioGlow Season)

Foundational thinking for a progress-tracking app for our FIRST LEGO League Challenge team. These documents capture the *concepts*; specific app design comes later.

## The one organizing idea

**The judging rubric is the source of truth.** Both judged components are scored on the same five phases — IDENTIFY → DESIGN → CREATE → ITERATE → COMMUNICATE — and judges score *evidence*. So every process we run and every field the app tracks exists to generate clear, dated evidence for a specific rubric row.

## The four FLL components at a glance

| Component | How it's scored | Our tracking focus |
|---|---|---|
| **Innovation Project** | Rubric (presentation) | Research, decisions, expert feedback, iterations |
| **Robot Design** | Rubric (explanation) | Tradeoff decisions with data, testing, ownership |
| **Core Values** | Woven through both rubrics + event; 25% of Champion's score | Daily moments, contribution balance, spotlight |
| **Robot Game** | Match score (objective) | Mission inventory, run plan, score progression |

## Additional things worth tracking (suggestions)

**Season logistics**
- **Season calendar:** meeting schedule, scrimmages, tournament date(s), and working-backward deadlines (e.g., "robot code freeze," "presentation locked," "dress rehearsal")
- **Attendance** — also quietly feeds the "all team members" evidence
- **Parts/materials inventory** and budget (for both robot and Innovation Project prototype)

**Competition readiness**
- **Rubric self-assessment:** monthly, the team rates itself 1–4 on all 20 rubric rows; the dashboard heat-maps it. This is the single best "are we ready?" view and teaches the students to think like judges
- **Mock judging sessions:** schedule and results (have another coach/parent judge with the real rubric)
- **Tournament-day checklists:** pit setup, what to bring, pre-match checklist, program-launch cheat sheet

**Evidence & memory**
- **Code version log:** what changed in each program and when (even just dated exports) — ITERATE evidence
- **Expert/mentor contact log** (shared with the Innovation Project but useful program-wide)
- **Outreach log:** demos, community events, helping other teams (Core Values gold)
- **Skills matrix:** which students can do what (gyro turns, My Blocks, CAD, presenting) at season start vs. end — a great Discovery story and a coaching tool
- **Photo/video library** with meeting-date tags — feeds everything: notebook, spotlight, presentation

**Team health**
- **Fun tracker:** a silly-but-real meeting fun rating from the students. Fun is a scored value; a drooping fun line is an early-warning system
- **Student reflections:** one sentence per student every few weeks ("what I'm proud of / what I want to learn") — becomes COMMUNICATE material and end-of-season keepsake
