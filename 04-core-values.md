# Core Values — Woven Through Everything

**Why this matters more than it looks:** there is no separate Core Values presentation. Judges evaluate Core Values *through* the Innovation Project and Robot Design sessions and across the whole event — and Core Values are **25% of the Champion's score**. Eleven of the twenty rubric rows (the ⚙️ rows in `00-judging-rubric.md`) count dually toward Core Values. You can't cram for this; you can only live it all season and *show the evidence*.

## The Six Core Values

| Value | What judges look for |
|---|---|
| **Teamwork** | We are stronger when we work together |
| **Discovery** | We explore new skills and ideas |
| **Inclusion** | We respect each other and embrace our differences |
| **Innovation** | We use creativity and persistence to solve problems |
| **Impact** | We apply what we learn to improve our world |
| **Fun** | We enjoy and celebrate what we do! |

Plus the two umbrella ideas: **Gracious Professionalism®** (compete hard, treat everyone with respect) and **Coopertition®** (helping other teams even while competing against them — logging any help we give/get from other teams is gold-star evidence).

## Daily Log Integration

Every meeting's log entry includes a lightweight Core Values section:

- **Core Values moment of the day** — one observed moment, tagged with which value it showed and who was involved. (Rotating "spotter" role: a different student watches for the moment each meeting.)
- **Value of the day tally** — which values showed up today (multi-select). Over a season this becomes a radar/heat chart showing whether we're strong on Fun but light on Inclusion, etc.
- **Help given / received** — any Coopertition or mentoring moment.

Keep it to 60 seconds at the end of each meeting — sustainable beats thorough.

## Team Spotlight (dashboard section)

A page/card per student:

| Field | Notes |
|---|---|
| Photo(s) | Upload team and individual photos; also action shots from meetings |
| Name & role | e.g., lead builder, programmer, project researcher, drive team |
| Favorite Core Value | And a sentence on why, in their own words |
| Missions programmed | Pulled from the mission inventory in `03-robot-game.md` |
| Attachments built | Pulled from the same inventory |
| Innovation Project role | e.g., research lead, prototype builder, presenter |
| Proudest moment this season | Their own words — this doubles as COMMUNICATE material |

Plus a team-level spotlight: team photo gallery, team name/number, season timeline of favorite moments.

## Other Core Values evidence worth tracking

- **Discovery log:** new skills each student learned this season (first time programming a gyro turn, first interview with an expert…)
- **Inclusion check:** does the ownership data (missions/attachments/IP roles) show everyone contributing? The dashboard can flag imbalances early — that's the "all team members" rubric rows made visible.
- **Celebrations:** milestones celebrated (first 100-point match, prototype done). Photos of these feed the "pride and enthusiasm" rubric rows.
- **Outreach:** demos for other classes, community events, helping rookie teams.
